2. Electron magnetic moment. W: https://physics.nist.gov/cgi-bin/cuu/Value?muem (NIST CODATA 2022): mu_e = -9.284 764 6917(29) x 10^-24 J T^-1.

3. Magnetic susceptibility. W: arXiv cond-mat/0207368 ("Magnetism of carbon-based materials", a review; the saved tool-result PDF text was read with pdftotext, lines 304):
   - graphite along the c-axis: chi_perp = -(22 - 50) x 10^-6 emu/g, attributed to itinerant pi electrons.
   - graphite parallel to the basal plane: "usually accepted" -5 x 10^-7 emu/g, but "experimental evidence that this component is paramagnetic, +2 x 10^-6 emu/g [95]"; negative in-plane values may come from sample misalignment.
   - diamond: the review says the low-field moment is non-linear for graphite, C60 and diamond; it gives no diamond number in the quoted passage.
   - diamond number: W search result quoting a susceptibility table (Wikipedia 'Magnetic susceptibility', mass susceptibility -4.9 x 10^-7 cm^3/g, molar -5.9 x 10^-6 cm^3/mol, room temperature). Secondary, the same search found that table's graphite row looked mislabelled. Treat the diamond value as unverified.
   - The c-axis value is not a constant: one recent study (named in the search summary, not opened) finds tens of percent variation between bulk samples.
