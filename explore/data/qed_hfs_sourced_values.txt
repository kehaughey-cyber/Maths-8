Cross-check made on retrieval: alpha * X_total of the first source gives -0.01316 (Z = 67), -0.01711 (75), -0.02255 (83); the second source's self-energy column gives -0.0132, -0.0171, -0.0226: the two sources agree.
Convention note (inferred, to be checked against the PDFs): the tabulated self-energy tends to the free-electron anomalous-moment term alpha/(2 pi) as Z -> 0 (F(0) = 1/2), so it contains the Schwinger term that is already inside this repository's E_nr (which uses the measured electron moment).
